# 網站建置單頁 (Landing Page) UI 實作企劃書

> 此文件定義了 `WebDesign.tsx` 在終端客戶視角的呈現邏輯。
> 基於「Base + Add-on (底層+選配)」商業模式，將 6 個內部產品線整合為 **3 大展示卡片**。

---

## 網頁視覺流 (User Flow)

1. **Hero Section (吸睛開場)**：維持目前的動態科技感背景與「數位房地產」標題。
2. **Features (三大優勢)**：維持目前的 3 張 Glassmorphism 特色卡（速度、資安、擁有權）。
3. **Pricing & Plans (本次重構核心：第一層 3 張大卡)**。
4. **Detail Modals (彈出視窗：第二層選配細節)**。
5. **FAQ (手風琴)**：解答維護費與修改次數疑問。
6. **CTA (預約表單)**。

---

## 第一層：3 張產品主卡片設計 (Pricing & Plans)

在畫面上，我們會並排 (Desktop) / 垂直 (Mobile) 展示這三張卡片，資訊務必極致簡潔，絕不讓客戶陷入選擇障礙。

### 卡片一：輕量套版 (Template Starter)
- **定位**：預算導向、極速上線 (對應：無後台/有後台形象官網 & 一頁式)
- **視覺**：藍色系，簡約乾淨。
- **標示價格**：**$38,000 起**
- **特點短語**：高 CP 值、3-4 天極速上線、完美 RWD 動效。
- **按鈕**：`詳細方案與規格 ➔`（點擊開啟 Modal A）

### 卡片二：半客製 / 樂高拼裝 (Semi-Custom) 👑 [主推]
- **定位**：彈性擴充、企業首選 (對應：有後台加上各種 Add-ony，含輕量電商)
- **視覺**：深色背景 (Slate-900)，加上青色 (Cyan) 霓虹光暈，帶有「熱銷推薦」徽章。
- **標示價格**：**$38,000 起 + 彈性選配**
- **特點短語**：買底盤加選配、預算花在刀口上、隨時支援電商與會員擴充。
- **按鈕**：`查看選配加購清單 ➔`（點擊開啟 Modal B）

### 卡片三：全客製化 (Full Custom)
- **定位**：量身打造、大型系統 (對應：全客製化形象/平台)
- **視覺**：紫色/漸層系，尊榮內斂。
- **標示價格**：**$150,000 起**
- **特點短語**：從零開始的 UI/UX 設計、處理複雜商業邏輯與 API 串接。
- **按鈕**：`專人訪談評估 ➔`（點擊開啟 Modal C）

---

## 第二層：詳細資訊彈窗 (Modals)

當客戶點擊主卡片上的按鈕時，畫面上會浮現一個帶有模糊背景 (Backdrop Blur) 的彈出視窗，並以 `Framer Motion` 由下而上流暢滑入。

### Modal A (輕量套版的內容)
- **表格呈現**：無後台 ($38,000) vs 有後台 ($58,000) 的打勾對照表。
- **說明**：包含 1 年網域與主機方案。
- **流程**：客戶提供素材 ➔ 我們快速套用 ➔ 交付驗收。

### Modal B (樂高拼裝的內容) 🔥 商業模式的核心火力
- **基底說明**：先擁有一套基礎官網設計 ($38,000 起)。
- **加購選單 (Add-ons Menu)**：用類似「菜單勾選」的 UI 設計，列出以下圖文並茂的模組：
  - 🛒 **輕量電商模組** (+ $50,000)：綠界金流、商品管理。
  - 👤 **會員系統模組** (+ $22,000)：登入/訂單查詢。
  - 📝 **動態後台升級** (+ $25,000)：讓你隨時改圖改字。
  - 📄 **增加專屬分頁** (+ $8,000 / 頁)
- **文案引導**：「像拼樂高一樣，打造最適合您現階段預算的網站！」

### Modal C (全客製化的內容)
- **開發流程**：需求訪談 ➔ UI/UX 繪製 ➔ 程式開發 ➔ 壓力測試。
- **適合對象**：包含 ERP 串接、複雜會員分級、百萬流量級距活動網站。
